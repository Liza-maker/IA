1/ Lancez Windows PowerShell grâce à la barre de recherche Windows et écrivez
“PowerShell”

2/ Allez dans le répertoire souhaitée afin de télécharger le dossier avec la commande
suivante : git clone https://github.com/Liza-maker/IA
A écrire dans votre console PowerShell

3/ Allez dans votre explorateur de fichier et ouvrez là où vous avez effectué le git clone (ici dans Documents\Test)

4/ Lancer Lance_scripts.ps1
5/ Attendre 5 secondes
6/ Accéder à http://localhost:5001/doc.html
7/ Profiter du site web

8/ Après fermeture du site web, vous pouvez fermer les fenêtres de python et l'invite de commande ouverte qui se sont ouvertes.
